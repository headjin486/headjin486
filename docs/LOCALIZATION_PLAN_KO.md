# EARTH UNLOCK 다국어 지원 설계

## 목표
EARTH UNLOCK을 한국 전용 앱이 아닌 글로벌 서비스로 개발한다. 화면 문구를 코드에 직접 작성하지 않고 Android 리소스 기반으로 관리해 번역 언어를 추가해도 기능 코드를 반복 수정하지 않도록 한다.

## 출시 초기 언어
- 한국어(ko): 기본 개발 언어
- 영어(en): 글로벌 기본 언어 및 지원하지 않는 언어의 대체 언어

## 후속 언어
- 일본어(ja)를 우선 추가 후보로 둔다.
- 이후 실제 이용자 국가·언어 통계를 보고 스페인어, 중국어 간체 등 추가 여부를 결정한다.

## 언어 선택 동작
1. 최초 실행 시 Android 시스템 앱 언어 설정을 따른다.
2. 지원 언어가 아니면 영어를 사용한다.
3. 설정 화면에서 사용자가 언어를 직접 선택할 수 있다.
4. 사용자가 직접 선택한 언어는 앱 재실행 후에도 유지한다.
5. 언어 변경은 계정, 닉네임, SQLite 탐험 기록, 클라우드 백업 데이터에 영향을 주지 않는다.
6. 앱 재시작 없이 즉시 반영할 수 있는 구조를 우선 검토하되, Android 구성 변경 안정성이 더 중요하면 Activity 재생성을 사용한다.

## 구현 원칙
- 모든 UI 문자열은 Android string resources로 이동한다. 예: `res/values/strings.xml`, `res/values-ko/strings.xml`, `res/values-en/strings.xml`.
- 화면 제목, 버튼, 안내문, 권한 설명, 오류, 온보딩, 설정, 랭킹, 닉네임 입력/검증 메시지를 모두 번역 대상으로 관리한다.
- 문자열을 코드에 하드코딩하지 않는다. 번역 누락 검사를 빌드/정적 검사에 포함한다.
- 문자열 연결로 문장을 조립하지 말고 포맷 문자열과 복수형 리소스를 사용한다.
- 날짜, 시간, 숫자, 소수점, 백분율은 사용자 Locale에 맞게 표시한다.
- 면적 단위는 m²/km²를 기본으로 하되, 지역별 표시 정책을 검토하고 단위 선택 가능성을 열어 둔다.
- 지도 타일의 지명/도로 라벨 언어는 앱 UI 번역과 별개로 지도 SDK의 언어 설정 지원 여부를 확인한다.
- 닉네임과 글로벌 랭킹은 다양한 유니코드 문자를 안전하게 표시하도록 폰트·정렬·검증 규칙을 설계한다.

## 품질 검증
- 한국어·영어 화면의 잘림, 줄바꿈, 버튼 너비, 글자 크기를 확인한다.
- 번역 누락 시 영어 기본 문자열로 안전하게 대체한다.
- 언어 변경 전후에 로컬 탐험 기록과 계정 데이터가 유지되는지 확인한다.
- 시스템 언어 변경 및 앱 내 수동 언어 변경을 각각 테스트한다.

## 패키지 ID
- 사용자가 제안에 동의한 후보: `com.earthunlock.app`
- 실제 소스 변경 및 Firebase 등록 전에 패키지 ID를 일괄 변경하고, 서명된 업데이트 설치와 데이터베이스 마이그레이션을 검증한다.
- Google Play 최초 등록 전 패키지 ID의 사용 가능 여부와 브랜드/상표 충돌을 확인한다.
