# EARTH UNLOCK v0.8.0 — 적응형 GPS 배터리 최적화

## 변경 사항
- 이동 중에는 고정밀 GPS 요청을 5초 간격으로 유지한다.
- 유효한 위치 샘플에서 3회 연속 정지 상태가 감지되면 요청 간격을 15초로 완화한다.
- 이동이 다시 감지되면 5초 간격으로 복귀한다.
- 정지 감지에는 이동 속도와 직전 위치 대비 변위를 함께 사용한다.
- 고정밀 위치 정확도 검증을 통과한 샘플만 탐험 저장 및 이동 상태 판정에 사용한다.
- 빠른 추적 모드에서는 주기적인 정지 샘플을 받을 수 있도록 최소 이동 거리 필터를 해제한다.
- GPS 위치 마커 갱신은 유지하고, 안개 지도 재계산은 최대 10초 간격으로 제한한다.

## 데이터 및 안전성
- GPS 위치 기록과 해금 격자 저장은 기존 SQLite 트랜잭션 흐름을 유지한다.
- 느린 추적 모드에서도 위치 간 보간을 통해 경로 단절을 줄인다.
- 위치 권한 또는 위치 제공자 오류가 발생하면 추적 서비스를 중단한다.

## 검증 상태
- 단위 테스트와 GitHub Actions 빌드 결과 확인 필요.
- 실제 기기 배터리 소모량 및 장시간 이동 경로 연속성은 실기기 검증 전이며, 절감률을 보장하지 않는다.
